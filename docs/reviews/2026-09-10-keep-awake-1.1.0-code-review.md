### Independent privileged review evidence

The bounded Astra review found two controller lifecycle regressions and one partial-launch failure gap in an earlier snapshot:

- Administrator approval time counted against the selected duration.
- A terminal helper journal could return the controller to idle while authorization was still pending, allowing another authorization attempt.
- An unknown authorization transport failure could report idle without restoration evidence.

The final controller resets the duration origin after confirmed activation, stays in `starting` until the authorization callback returns, and enters `stopping` when launch ownership is uncertain. An isolated probe using fake authorization, power, activity, process, and clock dependencies recorded these outcomes:

```text
Delayed authorization: running remaining: 60.0
Pending authorization: starting requests: 1 activityEnds: 0
Failed transport before ownership journal: stopping activityEnds: 0
```

The same review confirmed that recovery takes the exclusive root lock before reading the journal or restoring sleep. Shared.swift SHA-256 `ee39304d3fba63b238e5442627471adaf20076d620b08bc683f09ac3e0adaec2` and Helper.swift SHA-256 `a03a425de40f9132ede07f67e3e1ba971870553bbdd76caac88c59df89dae0c2` still match its final snapshot. The later App.swift facade simplification compiled under strict concurrency and passed the final controller suite.

No real administrator prompt, `pmset` mutation, installed-app replacement, or physical power test occurred in that independent pass.
